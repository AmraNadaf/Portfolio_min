Queue-decoupled narration

A Lambda invocation is capped at fifteen minutes. A book takes about twenty. So the work splits: an API Lambda accepts the job, a worker Lambda narrates, and an SQS queue sits between them.

The book is chunked poem by poem, each poem is its own queued message, and a failure retries on its own up to three times without restarting the book.
